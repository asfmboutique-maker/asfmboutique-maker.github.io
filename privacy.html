Privacy Policy

Last updated: 25 November 2026

Data we access

When a creator authorizes the app, TikTok provides an access token and basic profile information (open ID, nickname, avatar) for the scopes the creator approves: user.info.basic, video.upload and video.publish.

How we use it

Only to show which account is connected and to upload and publish the creator's own videos when the creator asks. We do not read other users' data, do not sell or share any data, and do not use it for advertising.

Where it is stored

Access and refresh tokens are stored only on the creator's own computer, in a private local file. No external server or database is used.

Retention and deletion

Tokens are kept only while the creator uses the app. A creator can revoke access at any time in TikTok (Settings → Security → Manage app permissions); the local file is then deleted.

Children

The app is not intended for anyone under 18.

Contact

Questions about this policy: send a direct message to @corps.decode on Instagram or TikTok.
